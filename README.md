# TLC Analyzer Pro (V5.0)

Professional Quantitative Thin Layer Chromatography Analysis for Mobile and Desktop.

## Features
- **PWA Ready**: Install as a mobile app for field work.
- **Advanced Algorithms**: LoG, Adaptive, and Watershed detection.
- **High-End UI**: Premium design with real-time feedback.
- **Quantification**: Precise Rf, Peak Height, and Area calculation.

## Tech Stack
- **Frontend**: Vanilla JS, HTML5 Canvas, CSS3 (Modern Glassmorphism).
- **Backend**: Python, Flask, OpenCV, Scikit-Image.

## Deployment
- **GitHub**: Source code and version control.
- **Hugging Face Spaces**: Live demo and processing.
